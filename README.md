# DartClaw Scoop bucket

Official [Scoop](https://scoop.sh/) bucket for DartClaw.

The bucket is ready for publication. Its first installable manifest will be generated when DartClaw publishes a
Windows x64 release asset. Until then, use the PowerShell installer documented in the
[DartClaw Windows guide](https://github.com/DartClaw/dartclaw/blob/main/docs/guide/windows.md).

After the first manifest is published:

```powershell
scoop bucket add dartclaw https://github.com/DartClaw/scoop-dartclaw
scoop install dartclaw/dartclaw
```

Files under `bucket/` are generated by DartClaw's release workflow from a version-locked template and the published
Windows archive checksum. Do not edit generated manifests by hand.
